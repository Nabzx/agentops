# `docs/`

evaluation reports. Start here:

- **[portfolio.md](portfolio.md)** — CV bullets, project story and interview Q&A.
- **[frontend-dashboard.md](frontend-dashboard.md)** — the operator console (S9).
- **[screenshots/](screenshots/)** — dashboard screenshots captured from the running app.

The per-component notes (rules, retrieval, model layer, workflow, approvals, outbox, audit,
observability, security, evaluations) are catalogued in the
[architecture documentation index](architecture.md#documentation-index).
